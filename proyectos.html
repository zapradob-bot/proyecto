Áreas de enfoque

Estas son las líneas de trabajo que estoy fortaleciendo durante mi formación. Cada tarjeta resume un campo, su propósito y las habilidades que practico.

Desarrollo Web

Diseño y construyo páginas con HTML5 semántico y CSS3, usando Flexbox y Grid para organizar el contenido. Me interesa que el resultado sea claro, responsive y fácil de navegar.

  • Estructura semántica: header, nav, main, footer
  • Estilos con Flexbox, Grid y modelo de caja
  • Accesibilidad: contraste, foco visible y textos alternativos

Bases de Datos

Estudio el modelado de datos, la integridad de la información y las consultas para recuperar, filtrar y relacionar registros. Quiero diseñar estructuras coherentes que sirvan a aplicaciones reales.

  • Modelado entidad-relación y normalización
  • Consultas para insertar, actualizar y consultar datos
  • Relación entre la base de datos y el desarrollo de software

Programación

Practico la resolución de problemas mediante algoritmos y código limpio. Busco entender no solo cómo funciona un programa, sino cómo se puede mantener y explicar con claridad.

  • Pensamiento lógico y descomposición de problemas
  • Estructuras de control y organización del código
  • Buenas prácticas para proyectos académicos

Redes

Me interesa comprender cómo se conectan los dispositivos, cómo viaja la información y qué elementos hacen posible un servicio estable. Es un complemento natural al desarrollo y a las bases de datos.

  • Fundamentos de comunicación entre sistemas
  • Infraestructura, servidores y conectividad
  • Relación entre redes, seguridad y aplicaciones web
